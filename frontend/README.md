# SettleCart Frontend

Next.js 16 application for SettleCart Marketplace landing page and waitlist portal.

## Quick Start

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build

# Start production server
npm run start
```

For complete project documentation, environment variable setup, and Vercel deployment guides, refer to the [Root README](../README.md).
